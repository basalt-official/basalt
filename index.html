FAQ

Quick answers

Is this for Flutter?

No. Basalt is for React Native / Expo in VS Code or Cursor.

Does it work in Cursor?

Yes. Install from Open VSX, or use the VS Code Marketplace listing if your Cursor build supports it.

Does it edit my real source?

Yes. Drags and text edits write into your project files — not a separate mockup.

Do I need an account?

Not for the editor. A free account is only for Marketplace buy / Submit / Dashboard sync.

Can I swap image assets from Basalt?

Not yet. You can select and layout Image views; adding/replacing files in assets/ is on the roadmap.
